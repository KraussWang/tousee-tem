# TEM 外观装配交付与检查

## 交付

- `TEM_assembly.blend`：Blender 5.2 可编辑工程，13 个 L1 部件以 `parts.json` 的 id 命名根节点，场景为毫米、Z 向上，根节点位于各自 `datum`。
- `assets/<id>_full.glb`：13 个局部基准点资产；GLB 为 glTF 标准米制、Y 向上，根节点自带 `0.001` 比例。原始 `../../models/source/*_full.glb` 未修改。
- `previews/assembly_{front,left,right,top,iso}.png`：装配正、左、右、俯、斜视图。`assembly.json` 保存源包围盒、缩放及基准点；`verification.json` 保存逐件回导结果。
- 可复现：`blender -b --python scripts/assemble_blender.py`，然后运行 `blender -b --python scripts/verify_assembly.py` 和 `blender -b outputs/blender-assembly/TEM_assembly.blend --python scripts/verify_scene.py`。脚本从项目根目录执行。`verify_scene.py` 的逐项数值写入 `scene_verification.json`。
- 双目镜接口：`data/interfaces.json` 记录 vc 安装座与 bino 背板。如需微调，在 `.blend` 中移动/旋转 Empty `vc.bino_seat`、`bino.mount`，运行 `blender -b outputs/blender-assembly/TEM_assembly.blend --python scripts/capture_interfaces.py` 回写（加 `-- --estimate` 则按网格重新估算），再重跑装配，并把打印的 `BINO_MATED` datum/rotation 同步进 `parts.json` 与 PRD §7.2。

## 侧挂件修复（2026-11-10 第二轮）

根因：
- gonio 原先用 `Rotation(+90°,Z)` 把源杆转反，样品座扁舌朝外，手柄埋进 ol；同时 X/Y 被非等比拉伸了 1.64/1.70 倍。
- ol 生成网格相对四视图左右镜像，大测角台口在 −X。
- il 网格的选区光阑口在 +Y（180°）。
- sa 整件沿 X 被拉伸了 2.35 倍（540/230），块体变扁、外伸约 340 mm。

| 项 | 修复前 | 修复后 | 做法 |

| il 选区光阑口 / 水管 | 180° / 0° | 265.9° / 约 90° | 绕光轴转 +90°，烘焙进网格 |

| sa 长度 | 外伸至 x = −540，块体被拉伸 2.35 倍 | 外伸至 x = −380（法兰面外 152 mm），块体等比 | 去掉整件拉伸；法兰贴合 il 口端面 x = −227.95；只拉长细杆 4.21 倍，4 孔光阑条刚性平移；工作端中心 (−1.0, 0.5, −226.9) |

`verify_scene.py` 新增断言并已通过：
- ol 测角台口、il 光阑口的方位角各自偏差 ≤ 15°；
- 两个法兰面与接口端面的 |Δx| ≤ 1 mm；
- 杆端到光轴 ≤ 3 mm（gonio 在第三轮放宽到 ≤ 10 mm）；
- gonio 手柄位于镜筒外；
- sa 外伸 ≤ 200 mm。

gonio/ol、sa/il 的三角面相交数分别为 57 和 60，只记录、不断言。原因是生成的接口孔疑似被封堵，杆穿过封堵面时必然相交。

残留：
- sa 杆轴相对 il 口中心偏 y −2.4。

参数在 `assemble_blender.py` 的 `SIDE_RODS`、`MIRROR_X`、`AXIAL_YAW` 中。

## 已核查

- 13/13 个 GLB 均可由 Blender 5.2 回导；根节点 id、13 件数量和 `screen` 的 4 个子网格保留。共 417,161 三角面，导出文件合计约 74.38 MiB；最大单件 `screen` 为 10.41 MiB。贴图不超过 2048×2048。
- 轴线件的基准点 X/Y 均取 0，根节点坐标与 `parts.json` 一致。枪、加速管、聚光镜、物镜、中间镜、投影镜、观察室、底座的回导高度与目标差 < 5 mm；盒体外包络和镜筒半径做了相应定尺。
- 网格级对准（`verify_scene.py` 断言）：gun、accel、cl、ol、il、pl 的上下法兰拟合圆心及 vc 底法兰圆心距光轴 ≤ 2 mm（实测 ≤ 0.04 mm）；相邻件 Z 间隙 ≤ 1 mm；vc 偏转 ≤ 0.5°；bino 贴合点距 ≤ 2 mm、角度 ≤ 2°；bino 与 vc/pl/il/screen 无三角面相交。
- 测角台与选区光阑的内伸端均按实测接口端面距离（249.49 / 227.95 mm）放至光轴；大、小荧光屏中心在装配姿态下分别位于 z = −830 和 −730 mm。预览中主列、观察室、底座可组成一台外观整机。
- `screen_full.glb` 原始资产为 26,245 三角面、10.39 MiB、4 个网格、4 张内嵌贴图；更新后的 `pl_full.glb` 为 43,258 三角面、5.30 MiB，装配预览中外轮廓已接近圆形。

## 未通过与待复核

1. **几何精度**：原始生成网格存在孔口封堵或浅凹、粗糙法兰、接口方位偏差。特别是 `ol`、`base` 的疑似封堵孔，`sa` 的工作孔，以及 `pl` 中心孔贯穿性，尚不能凭外观预览判为通过。镜筒法兰外缘同轴度已测并通过（见上）；法兰螺栓孔位、gonio/sa 与镜筒相接处的穿模尚未测量。base 仍按包围盒居中，其顶板 Ø300 开口与 vc 底法兰的同心度未单独核验。
2. **荧光屏**：源大屏已倾斜；局部姿态已抵消后再应用 PRD 的 +30° 装配旋转，小屏中心按全局 z +100 mm 放置。大屏网格仍有约 29 mm 的轴向包络，明显厚于 PRD 的 6 mm，应修模。小屏支撑件也需人工检查是否与观察室内壁相接。
3. **侧挂部件**：`gonio` 和 `sa` 已按剖面实测法兰面与杆轴贴合（见上节）。杆穿过接口封堵面的相交仍需修模，样品座 Ø3 孔、光阑条工作孔的贯穿性也未验证。`film` 原件是合并网格，无法单独抽出两只盒；保留一个 L1 根节点。
4. **面数预算**：`gun` 为 67,202 三角面，超过 PRD 的单件 50,000 面限额；本轮未重拓扑。
5. **可见性**：`screen` 和 `film` 位于封闭的观察室/照相室内，外观预览无法验收其内部装配；需在后续半剖资产或隐藏外壳状态下复核。爆炸、剖切、光路和浏览器交互不在本轮交付中。

## three.js 坐标接口

导出的 GLB 节点世界尺寸为米，Y 向上；`parts.json` 仍是毫米、Z 向上。加载时应将 `datum` 毫米转换成米，并把 GLB 的 +Y 映射到场景 +Z（绕 X 轴 **+90°**），不要再给已经带有 0.001 根比例的资产乘 0.001。PRD §5.1 当前写的 `rotateX(−90°)` 和额外 `scale(0.001)` 与本批 GLB 的实际导出结果不符；浏览器集成前需统一这一约定。

## 半剖验收（2026-11-16）

范围：gun / accel / cl / ol / il / pl / vc 七个 `<id>_section.glb`。

检查方法：`scripts/inspect_section.py` 用同一机位渲染外观与半剖，共 7 个视角（front / iso / left / right / top / iso_back / low），输出到 `previews/inspect/`；`verify_sections.py` 另渲整列半剖 `previews/assembly_section_{front,iso}.png`。

根因：`split_shell` 按面中心划分侧挂件与壳体。生成网格用长扇形三角面把侧挂件连到镜筒外皮上，侧挂件整件保留、背后的外皮被剖去后，这些面就成了尖刺和残片。

| 部件 | 修复前 | 修复 |
| --- | --- | --- |
| 全部 | 侧挂件根部在 −Y 侧有尖刺 | `section_lib.split_shell`：在 −Y 侧，侧挂件的面还要求各顶点（向面心收 35%）满足判定；面积 < 60 mm² 的碎片删除（按顶点坐标判连通） |
| ol | +X 测角台口法兰缺面，圈内有扇形尖刺；顶法兰下沿有薄片伸向 −Y | 判定改为以测角台口轴为圆心、R123 圆内 x > 200 的面，排除镜筒外皮（法线径向）与顶法兰的底面/外缘；x < 214 处只保留法兰外缘 |
| gun | −Y 侧高压电缆根部呈锯齿；收紧判定后电缆悬空 | 该电缆插在被剖去的那半绝缘子上，改为随壳体剖切；+Y 电缆与离子泵保持整件 |
| accel | −X 两个浅凸小法兰的 −Y 半侧悬成开口薄壳 | 改为随外皮剖切（只保留 +X 执行器整件） |
| pl / il / cl | ±X 侧挂件根部尖刺 | 由通用规则修复 |

校验结果：7 个 `section_<id>.json` 的 failures 为空。三角面数分别为 gun 41,009、accel 26,664、cl 29,517、ol 22,004、il 23,165、pl 30,911、vc 7,381，均 ≤ 50k；单件 ≤ 6.6 MB。`verify_sections.py` 通过：+Y 半侧与外观的包围盒偏差 ≤ 0.22 mm（ol），7 件高度都从 datum 起、不超出各自高度，光轴在小荧光屏以上只被 gonio 样品座和 sa 光阑条挡住（两者都是设计上位于光轴上的件）。`verify_scene.py` 通过。材质：剖面 #E6E6E6，线圈铜色，极靴/磁轭铁灰，光阑条黄铜色，外壳沿用外观材质。

保留项（不影响装配视图）：
- 侧挂件按约定整件保留，从斜后方能看到其背面开口（原本贴在镜筒外皮上）。pl +X 执行器和 il +X 接头最明显。
- vc 底部 Ø300 开口边缘、顶法兰中心的生成网格呈锯齿，在装配中分别被 base 和 pl 遮住。
- accel −X 小法兰的螺孔内有红色斑点，外观贴图本身就有，不是半剖引入的。
- gonio / sa 网格上没有竖直通孔（`verify_sections` 的 warnings），光束直接画过去。
